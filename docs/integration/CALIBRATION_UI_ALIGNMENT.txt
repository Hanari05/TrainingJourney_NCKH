CALIBRATION UI ALIGNMENT — current backend project, updated 2026-11-01

This file replaces the old FE-only audit, which described a mock-provider
project and a previous evaluator. It does not describe the current runtime.

Current provider: BackendPoseProvider via WebSocket. camera_frame is decoded
from JPEG/base64 by PoseProvider and displayed without a second mirror or
joint overlay. Connection, fresh image and fresh tracking are separate checks.

The current calibration workflow and payload fields are documented in:
../../docs/CALIBRATION_UPDATE_20261101.md
(relative to project root: docs/CALIBRATION_UPDATE_20261101.md).

BE supplies a normalized T-pose calibration index. UI does not represent it
as a raw joint angle. Valid sample time drives progress, not ROM percentage.
UI ignores out-of-session/late results and has camera/session timeouts.
Layout uses containers and vertical scrolling at smaller sizes.

The 2026-11-01 FE completion pass changes presentation only. It does not
change the Python evaluator, its thresholds or the camera/DB services.
Real camera end-to-end validation and professional review remain necessary
separate acceptance steps; synthetic UI tests are not evidence of either.
